# 设计规范

## UI 设计原则
- 简洁直观，减少操作步骤
- 淡蓝色主题，视觉统一
- 单窗口 + 弹窗模式，避免多窗口混乱
- 关键操作有明确反馈（进度条 / 状态文字）

## 配色方案

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主背景 | 浅蓝 | `#E3F2FD` |
| 组件背景 | 淡蓝 | `#BBDEFB` |
| 强调色 | 深蓝 | `#1976D2` |
| 文字 | 深灰 | `#333333` |
| 成功状态 | 绿 | `#4CAF50` |
| 错误状态 | 红 | `#F44336` |

## 窗口设计

### 登录窗口
- 居中弹窗，约 360 × 300px
- 标题 "会议串场PPT生成器"
- 用户名输入框 + 密码输入框（掩码显示）
- 登录按钮（主按钮样式）
- 注册新账号链接（文字按钮）

### 注册窗口
- 居中弹窗，约 360 × 380px
- 用户名、密码、确认密码、API Key（选填）
- 注册按钮 + 返回登录链接

### 主窗口
- 约 900 × 700px，可调整大小
- 顶部标题栏显示 "会议串场PPT生成器" + 当前用户名
- 内容区分为 4 个功能模块区域，白色卡片式背景
- 底部固定 "一键生成PPT" 按钮 + 进度条

## 组件规范

| 组件 | 高度 | 说明 |
|------|------|------|
| 区域标题 | 24px | 加粗，深蓝色，左侧带颜色条 |
| 按钮 | 32px | 圆角 4px，深蓝背景白字 |
| 输入框 | 28px | 边框 1px `#BBDEFB`，focus 时 `#1976D2` |
| 表格行 | 28px | 交替白/淡蓝背景 |

## PPT 输出规范

### 页面结构（两种尺寸共用）
```
封面 → 开场提醒×2 → [每个环节: 分隔页 → 履历页 → 内容页 → 过渡页] → 总结分隔页 → 履历页 → 结束
```

### 尺寸参数
| 尺寸 | 宽度 | 高度 | 比例 |
|------|------|------|------|
| 16:9 宽屏 | 13.3" | 7.5" | 16:9 |
| 超宽屏(舞台LED) | 7.9" | 1.6" | 5:1 |

每种尺寸独立维护一套布局参数表（位置、字号、间距），参考两个模板 PPT 文件的实测数据。

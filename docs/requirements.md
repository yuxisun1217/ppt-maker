# 开发需求

## 项目概述
开发 Windows 桌面应用，根据会议日程图片和演讲者资料文件，自动生成会议串场 PPT。

## 功能需求

### F1. 用户系统
- 登录 / 注册
- 用户名 + 密码认证
- DeepSeek API Key 关联到用户账号
- 数据存储：SQLite 本地数据库

### F2. 演讲者资料管理
- 支持上传格式：DOCX、PDF、PPTX
- 每个文件包含：姓名、照片、文字简介
- 提取后以姓名为唯一标识存储
- UI 显示已识别演讲者列表

### F3. 会议日程识别
- 上传日程图片（JPEG / PNG）
- AI（DeepSeek Vision）识别每个环节的：
  - 顺序、时间段、中文标题、英文标题、演讲者姓名、机构、类型
- UI 表格展示识别结果，支持手动编辑

### F4. 模板图片设置
- 上传首页图片：用于封面 + 环节分隔页背景
- 上传内容页图片：用于履历页 + 内容页背景

### F5. PPT 生成
- 尺寸选择：16:9 宽屏 / 超宽屏（舞台 LED）
- 固定格式代码生成（不用 AI）
- 中英双语
- 结构：封面 → 开场提醒 → 各环节(分隔页+履历+内容+过渡) → 总结

### F6. UI 要求
- 简洁直观
- 淡蓝色主题
- Windows 10/11

## 输入输出

| 输入 | 格式 | 说明 |
|------|------|------|
| 演讲者资料 | DOCX / PDF / PPTX | 可多选上传 |
| 会议日程 | JPEG / PNG | 单图片 |
| 首页背景图 | PNG | 用于封面和分隔页 |
| 内容页背景图 | PNG | 用于履历页和内容页 |

| 输出 | 格式 | 说明 |
|------|------|------|
| 会议串场 PPT | PPTX | 16:9 或超宽屏 |

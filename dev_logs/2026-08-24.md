# 2026-08-24 开发日志

## 数据库迁移：SQLAlchemy ORM + PostgreSQL 支持

### 改动内容

1. **`database/models.py`（新增）** — SQLAlchemy 2.0 声明式模型：
   - `User`：原 users 表 + ocr_api_key + updated_at
   - `Speaker`：原 speakers 表 + bio_en/title + updated_at
   - `Task`：Web 生成任务（id=32位hex UUID、user_id FK、task_status、progress、
     message、options JSON、pptx_path、error、created_at/updated_at）
   - `Upload`：Web 上传记录（user_id FK、filename、path、size、时间戳）
2. **`database/db.py`（重写）** — SQLAlchemy 引擎/会话，DATABASE_URL 从 `.env`
   读取（默认 SQLite 锚定项目根目录）；**全部公开函数保持旧签名**（桌面端零改动）；
   新增 Task/Upload CRUD；`init_db()` 对旧 SQLite 库自动回填新增列
3. **Alembic** — `alembic.ini` + `alembic/env.py`（URL 读 .env）+ `versions/0001_initial.py`
   （4 张表初始迁移，upgrade/downgrade 已实测）；SQLite 自动开 batch 模式
4. **Web 层接入 DB** — `tasks.py` 任务注册表、`main_web.py` 上传注册表全部改为
   DB 持久化（替代内存 dict/manifest.json），**服务器重启后任务和上传不丢失**（已实测）
5. **`.env.example`** — 因 `.env*` 文件受权限规则写保护未能落盘，内容见日志末尾，
   需用户手动创建
6. **依赖** — requirements.txt 新增 SQLAlchemy/alembic/python-dotenv/psycopg2-binary；
   greenlet 需固定 3.0.3（Python 3.9 Windows 无新版预编译轮子）

## Web 前端对接后端 API（web/web_prototype.html）

### 改动内容

单文件 SPA，在已确认的原型 UI 上接入真实后端（Fetch API，页面不刷新不卡死）：

1. **步骤1 上传**：三个上传卡片全部改为真实交互（点击/拖拽均可）——
   演讲者资料（批量）、会议日程（单选）、背景图（首页/内容页各一张，替代原
   「PPT 模板」占位卡片）；文件选中即上传 `/api/upload`，chips 显示
   文件名+大小，可单独移除；新增「API 设置」卡片（DeepSeek Key 必填、
   OCR.space Key 可选、后端地址可改，全部存 localStorage）
2. **步骤2 配置**：原两张静态示例表格替换为「资料确认」卡片（真实文件名/大小
   + 必填/可选标记）；背景图改为真实图片预览（点击可替换）；屏幕尺寸/语言
   单选绑定到请求参数
3. **步骤3 生成**：一键生成 → `POST /api/generate` → 每 2s 轮询
   `GET /api/status`（递归 setTimeout + async/await，不阻塞 UI）→ 进度条/
   阶段提示实时更新 → 完成后结果卡片 + **自动触发下载**；失败显示错误横幅
   （含服务端错误摘要），可一键重试；轮询网络抖动 10s 后自动重试不中断任务
4. **错误处理**：统一 `api()` 封装提取后端 `detail` 字段；连接失败/上传失败/
   生成失败/参数缺失均有 toast 提示；步骤跳转带校验守卫（无日程、无 Key 拦截）
5. **历史记录侧边栏**：由静态示例改为本机 localStorage 真实记录（任务名/
   时间/状态），完成的任务可随时重新下载，支持搜索/单条删除/清空
6. **其他**：页脚版本 v0.2；顶部「账户设置」跳到 API 设置卡；「新建任务」
   重置全部状态；加载时探测后端连通性并显示徽标

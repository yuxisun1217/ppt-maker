## Linux 运行兼容性审计（Web 版）

### 结论

Web 版可在 Linux 直接运行，无需任何代码改动。审计项：

- **依赖**：requirements.txt 移除 pywin32 后全部为双平台包
  （python-pptx/Pillow/opencv-python-headless/psycopg2-binary/
  uvicorn[standard] 等均有 Linux wheel，Docker 用 python:3.12-slim）；
- **平台 API**：代码中无 win32/winreg/msvcrt/os.startfile/sys.platform
  等 Windows 专属调用；
- **路径**：无硬编码 Windows 路径/反斜杠；数据目录全部锚定
  `Path(__file__)`（BASE_DIR），与 CWD 无关，SQLite 相对路径也重定位到
  BASE_DIR；临时文件用 tempfile（跨平台）；
- **编码**：所有文件 I/O 为二进制或显式 `encoding='utf-8'`，
  无 GBK/cp936 依赖；日志 handler 显式 UTF-8；
- **SQLite 线程安全**：`check_same_thread=False` 已配置，FastAPI
  线程池/后台任务在 Linux 下行为一致；
- **字体**：PPT 仅写入字体名（Microsoft YaHei）由客户端渲染，
  服务端生成不依赖系统字体；
- **部署**：Dockerfile（slim + 单 worker）、docker-compose（Postgres
  alembic 迁移）、start_dev.sh 均 Linux 兼容；加密密钥兜底落
  `data/encryption.key`（web_data 卷内，跨重建持久）。

### 验证

- 端到端生成冒烟：不走 AI，用编辑数据（AgendaItem/Speaker）直接调
  `generate_ppt_async` → 9 页 PPTX（36KB）生成成功。
- 唯一注意项：容器内为 UTC 时区，任务时间戳为 UTC（仅展示层面）。

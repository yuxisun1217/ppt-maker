## 修复：登录成功后仍跳回登录页（会话 Cookie 未随请求发送）

### 现象

用户反馈：`POST /api/login -> 200` 后主页 `/api/me -> 401`，页面跳回登录页，循环。

### 原因

会话 Cookie 为 httpOnly + SameSite=Lax。用户用 `localhost` 打开页面而 API 请求发往
`127.0.0.1`（或反之）时，浏览器视为跨站请求，Lax Cookie 不随 fetch 发送，登录态丢失。
（file:// 打开页面时同样跨源。）

### 修复（双保险）

- 后端 `main_web.py`：
  - `_extract_token()` 优先读请求头 `X-Session-Token`，回退 Cookie
  - `/api/login`、`/api/register` 响应 JSON 中返回 `token`（同一会话令牌）
  - CORS 显式 `allow_origins` + `allow_credentials` 不变
- 前端四页（login/admin/web_prototype/settings）：
  - `apiBase()` 在 http(s) 访问时强制用 `location.origin`，不再读 localStorage 后端地址
    （该设置仅在 file:// 方式打开时生效）
  - 新增 `authFetch()`：统一 `credentials: 'include'` + 从 sessionStorage 取 token 加
    `X-Session-Token` 头；登录/注册成功后把 token 存入 sessionStorage，登出时清除

### 验证（8010 端口实测）

- 仅带 `X-Session-Token` 头（无 Cookie）→ `/api/me` 200 ✅
- 仅带 Cookie（无 token 头）→ `/api/me` 200 ✅
- 两者皆无 → 401 「未登录，请先登录」 ✅
- 临时测试账户已清理，8010 冒烟服务器已停止

### 遗留问题

- 用户需重启 8000 端口后端进程并在浏览器硬刷新（Ctrl+F5）以加载新页面代码
- ~~数据库中 `test`(id=1) 为管理员；用户注册的 `admin`(id=5) 是普通账户~~ 已按用户要求：
  `admin`(id=5) 提权为管理员，`test`(id=1) 已删除（其任务/上传记录 user_id 置 NULL 保留）

### 补充（08-27）：修复上传后不触发提取的 bug

现象：上传模版后无任何反应（无请求、无 toast）。后端日志确认请求从未发出。
原因：`uploadFiles` 用 `ACCEPT[kind]` 过滤，但 dropzone 绑定传入的 kind 是
`bg-home`/`bg-content`/`bg-template`，而 ACCEPT 键名是 `bg`/`template` →
`ACCEPT[kind]` 为 undefined → 过滤时直接抛 TypeError，fetch 未发出。
（此不匹配是旧代码遗留，背景**图片**直传此前同样静默失败。）
修复：ACCEPT 键名改为与 kind 一一对应（`bg-home`/`bg-content` 为图片正则、
`bg-template` 为 .pptx 正则），错误提示分支同步。已用 node 模拟
File 对象对 5 个 kind 的过滤/拒绝路径全部验证通过。
排查中还确认用户 8000 端口后端已含 `/api/template/background`（405 探测），
后端无需重启，浏览器 Ctrl+F5 刷新页面即可。

- 用户需重启 8000 端口后端进程并在浏览器硬刷新（Ctrl+F5）以加载新页面代码

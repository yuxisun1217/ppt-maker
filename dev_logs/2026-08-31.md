## Web 端演讲者卡片：姓名框宽度修复

### 问题

演讲者解析结果卡片中，姓名输入框渲染过窄（约 90-100px），较长姓名无法完整显示。

### 原因

- 共享的 `EDIT_CLS` 含 `w-full`（`web_prototype.html:990`）。
- Tailwind 生成的 CSS 中 `w-full` 排在 `w-20` 之后，导致职称框上的
  `w-20`（80px）被 `w-full`（width:100%）覆盖，职称框按 100% 宽度参与
  flex 布局并挤占空间，姓名框（`flex-1`）被压缩。

### 修改

`web_prototype.html` `speakerCardHtml()` 中姓名/职称两个输入框改用
内联固定宽度（内联样式优先级高于 class，确定生效）：

- 姓名：`style="width:15ch;flex:none"`（15 字符宽，不再参与伸缩）
- 职称：`style="width:5rem;flex:none"`（恢复设计值 80px）

### 验证

- 修改为纯前端布局改动，无后端影响。
- 建议在浏览器中打开页面重新解析验证：姓名框宽约 15 字符，职称框 80px。

## PPT 过场页嘉宾介绍行：缩进、左对齐、姓名职称不拆行

### 需求

1. 过场页（divider）嘉宾介绍行文本框左右两边各缩短 2 字符
2. 介绍行左对齐（原来居中）
3. 演讲者姓名与职称必须保持在同一行（如"张阿三 教授"），
   不允许换行时把"教授"拆到下一行

### 修改（`ppt_generator.py`）

- `_make_divider()`：嘉宾行文本框左移 2 字符、右缩 2 字符
  （`indent = 2 * d['speaker_sz']`，1 字符宽 ≈ 1 个字号，
  对 16:9 / 超宽屏两套参数表均适用），并传 `align=PP_ALIGN.LEFT`。
- `_format_name()`：姓名与职称之间、英文 "Prof." 前缀与姓名之间改用
  不换行空格 U+00A0（源码用可见的 ` ` 转义，避免不可见字符），
  英文姓名内部空格也替换为 U+00A0，整段姓名作为一个不可拆单元换行。
- `_spread_name()`：2 字中文姓名中间的空格（陈晨 → 陈 晨）也改为
  U+00A0，防止姓名本身被拆开。

### 验证

冒烟测试生成 16:9 PPT（张阿三 教授 / 李四 主任医师）：

- 文本框 off_x = 1.389"（0.5" + 2×32pt）、cx = 10.555"、
  `algn="l"`，与期望值逐字节一致
- XML 文本为 `张阿三 教授、李 四 主任医师`，
  姓名与职称之间均为 U+00A0
- `python -m py_compile ppt_generator.py` 通过

注：超宽屏未单独冒烟（同一代码路径，仅参数表不同）。
